# 超分节点

内置插件 `upscale` 提供 `upscale:media`，由服务端节点目录统一启停。应用启动时注册，前端源码由 Vite 按需加载，无需独立安装或构建。

- 每次处理一张图片或一段视频，可连接画布节点，或通过加号从资料库、画布及上传添加。多个源输入会明确提示，不静默取第一份，也不会取自身成品再次超分。
- 不提供自由提示词输入。图片 / 视频超分沿用对应生图 / 视频任务路径，把唯一源素材作为参考发送；提交空提示词后，服务端补入默认超分指令：减少噪点与压缩伪影、恢复自然纹理，保留主体身份、构图、几何、比例、色彩、光照、风格、文字及标识，避免虚构细节、过度锐化、光晕及过度平滑；解析模型参数后，将具体目标分辨率（如 4K）与质量写入自动提示词，显式 API 提示词不修改。图片面板仅显示「分辨率」和「质量」，不提供比例切换；服务端按源图真实宽高从已声明比例建议中选最接近项，再传给生图接口。视频额外要求帧间一致、不闪烁，保留运动、镜头、时序、帧率、时长及音频；这些属于模型指令，不是处理效果保证，接口插件按自身契约决定是否传给供应商。
- 模型来源于已启用的渠道目录及管理员排序，不猜供应商名称、不硬编码模型 ID；要求能力为图片或视频且有效模式下只有一个对应类型素材入口。声明 `mode` 时必须提供真实的 `upscale` 选项，未声明模式的单图编辑接口也可通过默认指令使用，但实际增强能力仍由模型决定。
- 图片只展示模型声明的 `resolution / quality` 目标字段，隐藏比例、尺寸、缩放和宽高切换；服务端仍可按源图比例自动填写接口声明的 `size` 或 `ratio`，不把旧节点值当作用户选择；视频继续展示模型声明的 `resolution / scale / size / width / height`。选项、建议、默认值及约束不另造一套；需要额外必填项且没有默认值的接口会按既有校验报错，应由管理员补全默认配置。
- 连接的素材在该节点提交时显式绑定到唯一命名素材入口，或作为分类参考提交；不会改变普通视频节点首尾帧绑定。参数、连线与结果保存在现有项目业务中，生成使用同一任务系统、事件通知、取消与结果回填，不在关闭面板时取消任务或手动覆盖成品。
- 成品仍输出对应图片或视频资源，可接入其他节点，下载沿用真实原件 MIME 后缀逻辑。
- 视频成品复用普通视频节点的首帧封面与居中播放按钮，保持原比例，点击后在节点内播放，结束恢复首帧；图片结果及下载操作不变。
- 底部参数面板随节点单选显示，取消或多选时与上方操作栏一起隐藏，不再提供单独的「编辑超分」工具栏按钮；开始超分、停止、素材添加及实际任务执行不变。
- 成品在节点工具栏提供与图片 / 视频相同的「存资产」，按真实媒体类型复用现有资产保留功能；节点外侧右上角统一以无背景小字显示比例、大小，视频额外显示秒数，与左侧名称同排，工具栏在该行上方，由画布外观的「参数信息」开关控制。下载按钮保留在媒体内部右上角，不遮挡参数或播放控件。
- 接口返回多份成品时，节点外侧右下角提供宿主统一纯数字按钮，打开共享结果 Dialog，点击已完成项设为主选；节点不显示叠卡，主选切换同步真实比例、大小及时长，沿用自动保存、撤销 / 重做及原有存资产 / 下游引用，不增加超分请求次数或未声明的批量参数。

图片工具栏原「AI 超分」仅为未实现的占位弹窗，现已连同自定义可选项及专用代码移除，不存在可迁移的算法或提示词；实际 AI 超分统一由本节点提供。图片工具栏的普通插值「放大」保留，不调用 AI 模型。

不修改或发布现有接口插件。DMC 自建视频超分脚本与接口要求视频 URL 路径带真实扩展名；后端新保存规则在构建并重启后，为新上传和生成的媒体原件及私有云对象统一保留真实后缀，签名地址沿用同一文件名。已有文件不自动改名，需要带真实后缀的新资产时可自行重新上传。仅重试旧任务不会改变原文件名，不设为公开，不静默改写已发布脚本，也不保证所有原件格式均符合供应商限制；DMC 真实下载、超分及成品保存仍需独立验收。

代码实施与未验收项目见 [CHANGELOG](../../../CHANGELOG.md#unreleased)。
