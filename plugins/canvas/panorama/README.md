# panorama 内置节点

查看 360° 等距柱状全景图，可读取上游图片或使用宿主生成面板。

上传全景图统一通过节点上方工具栏，空白和已有内容时均可使用，提示沿用「支持 2:1 等距柱状全景图」；空态只显示图标和提示，不放上传或 AI 生成按钮。换图上传成功后才替换当前图片，取消或失败保留原图，沿用私有资产、自动保存及撤销 / 重做。AI 创作面板随节点单选显示、取消选中时关闭，不再提供单独的工具栏开关。

此目录源码由前端直接打包，默认启用。管理员在「设置 → 节点插件」统一控制启停，普通用户无需安装。修改源码后由应用开发服务加载，发布时随应用构建；独立目录的构建产物只供源码开发参考，不自动安装。

节点运行约定见 [节点插件说明](../README.md)。
