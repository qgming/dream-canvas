# sticky-note 内置节点

彩色便利贴，支持拖动、双击编辑与选色。

正文编辑器上方为输入区，左下放大、右下完成；颜色通过节点上方编辑操作栏调整，保留预设和自选颜色，沿用画布自动保存与撤销 / 重做。仅便利贴采用此布局，其他生成节点仍保留右上角灵感库及放大入口。

正文编辑面板随节点单选显示，取消或多选时与上方操作栏一起隐藏，保留点击 / 双击及完成操作，不再提供重复的「编辑内容」工具栏按钮。

此目录源码由前端直接打包，默认启用。管理员在「设置 → 节点插件」统一控制启停，普通用户无需安装。修改源码后由应用开发服务加载，发布时随应用构建；独立目录的构建产物只供源码开发参考，不自动安装。

节点运行约定见 [节点插件说明](../README.md)。
