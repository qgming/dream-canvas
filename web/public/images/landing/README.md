# 首页功能截图

这十二张 WebP 来自当前项目的实际页面组件：`pages/canvas/project.tsx`、`pages/image/index.tsx`、`pages/video/index.tsx` 以及共享侧栏、表单、节点和结果组件。每个页面分别截取中文 / 英文、浅色 / 深色版本，视口为 1600 × 960。
