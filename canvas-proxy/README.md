# 梦想画布本地代理

为 AI 接口与 WebDAV 请求提供本机转发，解决浏览器跨域限制。请求体与鉴权信息由网页提供，代理不保存 API Key。

## 启动

需要 Node.js 18 或更高版本，在仓库根目录运行：

```bash
node canvas-proxy/index.js
```

默认地址为 `http://127.0.0.1:23210`，填入梦想画布「配置 → 本地代理」并开启。自定义地址：

```bash
node canvas-proxy/index.js --port 23210 --host 127.0.0.1
```

支持 `PORT`、`HOST` 环境变量。代理默认仅允许本机访问，不要直接暴露到公网。

## 转发规则

将完整目标 URL 接在代理地址后面，例如：

```text
http://127.0.0.1:23210/https://api.openai.com/v1/models
```

代理保留请求方法、请求体与必要的请求头，补充 CORS 响应头，并透传流式响应。根路径返回代理名称和版本，用于连接检测。

每条请求会在终端记录方法、目标 URL、状态与耗时，不落盘，不输出请求头或请求体。目标 URL 自身不应包含密钥。
